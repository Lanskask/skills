# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Anyone who installs `book-to-course` or `youtube-to-course` and turns a PDF book or a YouTube video/playlist into a
course, then studies it. The subject can be anything: physics, programming, history, business, public speaking, sport.
The typical session is on a laptop, 30-90 minutes at a time, often with the source PDF or video open beside the course.

## Product Purpose

A self-contained HTML course generated from one book or video: modules of short lessons ("screens") that explain the
source in plain words, with citations back to the exact PDF page or video timestamp, quizzes that ask the learner to
apply an idea, and a glossary with hover definitions. Success: the learner understands the source faster than by reading
it alone, and can always check a claim against the cited page or moment.

## Positioning

Every lesson is grounded: each screen cites the source page (`p.N`) or timestamp, verbatim quotes are marked as such,
and anything the course drew itself (diagrams, plots, derived formulas) is labelled as made for the course.

## Operating Context

- Output is static files opened from disk (`index.html` + CSS + JS), no server. Also printed.
- Generated by Python renderers (`skills/*/scripts/*_lib/render.py`, `ui.py`, `diagrams.py`) from validated lesson JSON.
  The renderer emits a fixed set of classes; the stylesheet and script must style and drive all of them.
- Content blocks: text with `[[term]]` glossary marks, cards, steps, callouts (accent/info/warning), source quote ↔
  plain words, math (KaTeX) with symbol tables, book figures, flow diagrams and plots (SVG), code ↔ explanation, task
  (exercise) cards, quizzes, key takeaways, cover page with module list, table of contents drawer with progress.
- Language of the course follows the source; labels are localised (en, ru).

## Capabilities and Constraints

- Light and dark theme with a manual switcher that remembers the choice (`localStorage`) and otherwise follows the OS.
- Keyboard navigation between modules, skip link, reduced-motion support, print styles, readable without JavaScript.
- One shared look for both skills; each skill ships its own copy of the assets so it installs standalone.
- Must not reuse code or text from third-party projects without a licence: the page design is written from scratch.
- External requests are limited to fonts and KaTeX from CDNs; everything else is local.

## Evidence on Hand

- Sample course: `make -C skills/book-to-course demo` renders the bundled example (a synthetic physics primer) to
  `/tmp/b2c-sample/course/index.html`.
- No real users, testimonials or metrics exist; none may be invented.

## Product Principles

1. Grounded over fluent: the source citation is always one glance away.
2. Long reading comes first: comfort over a 60-minute session beats first-impression flash.
3. Subject-neutral: the look must suit a history book as well as a physics textbook.
4. Works as a plain file: offline, printable, no build step.

## Accessibility & Inclusion

WCAG AA contrast in both themes, visible focus, full keyboard use, `prefers-reduced-motion` respected.
