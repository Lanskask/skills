# Module brief (parallel path, 6+ modules)

Write one per module to `work/briefs/Mx.md`, then give each subagent *only* its brief plus the files it lists.
Subagents never receive the PDF, other modules' briefs, or the full chapters.

- **Key insight:** [one thing the learner leaves with]
- **Why care:** [what it lets them do]
- **Lessons:** [L-ids with titles and objectives, copied from outline.json]
- **Pack files:** `work/selections/L-xx.md` for each lesson (already generated by `b2c.py select`)
- **Known gaps:** [lessons whose pack says needs_more=true and which pages to `read`]
- **Previous / next module:** [titles + one line each, for transitions]
- **Style notes:** [language, accent, terms already defined earlier that need no new tooltip]
- **Must read:** `templates/rubric.md`, `templates/lesson.md`, `templates/lesson.schema.json`, `templates/example/L-01.json`
- **Output:** `work/drafts/L-xx.json` for each lesson, then run `b2c.py validate --stage lesson --lesson L-xx` and fix until it passes.
